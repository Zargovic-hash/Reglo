# Migrations SQL

Le projet ne contient pas encore de lanceur de migrations automatique. Exécutez les scripts de ce dossier, dans leur ordre chronologique, sur l'environnement cible pendant une fenêtre de maintenance.

Le script `20260720_add_reglementation_filter_indexes.sql` ne modifie aucune donnée : il ajoute uniquement des index nécessaires aux filtres et à la recherche de la réglementation.
